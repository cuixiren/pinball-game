# Pinball Game

一个基于 **Matter.js** 的浏览器弹珠机小游戏。玩家先投注金币，再随机抽取本局倍率，通过右侧拉杆控制发射力度，让钢珠落入奖励洞口来赢取奖励。

## 游戏特点

- 纯前端实现，打开页面即可游玩
- 使用 Matter.js 驱动物理碰撞与弹珠运动
- 支持投注、倍率抽取、预计奖励显示
- 右侧拉杆发射，力度可视化
- 12 个落洞区域，随机生成本局奖励灯位
- 命中奖励洞口后触发金币结算与动画反馈
- `v2` 版本对顶部信息面板做了电子屏风格优化

## 玩法说明

1. 点击 `+1` 或 `+10` 增加当前投注。
2. 当投注金额达到可开始条件后，点击 `开始游戏`。
3. 系统会为本局随机抽取倍率，并随机点亮若干奖励洞口。
4. 按住右侧拉杆向下拖动，松手后发射钢珠。
5. 如果钢珠落入奖励洞口，则按 `投注 × 倍率` 结算奖励；否则扣除本局投注。

## 运行方式

这个项目不依赖打包工具，直接用浏览器打开 `弹珠游戏_v1.html` 即可运行。

如果浏览器对本地脚本加载有限制，也可以使用一个简单的本地静态服务器后再访问页面。

## 项目文件

- `弹珠游戏_v1.html`：主游戏页面，包含界面、物理场景和游戏逻辑
- `pachinko_config.js`：倍率权重配置

## 技术说明

- 物理引擎：Matter.js
- 主要机制：
  - 钢珠发射与弹簧平台联动
  - 钉阵碰撞与导流结构
  - 洞口传感器检测落点
  - 投注、倍率、奖励与金币结算系统

## 倍率规则

当前倍率概率配置位于 `pachinko_config.js`：

```js
const MULTIPLIER_WEIGHTS = { 2: 45, 4: 35, 6: 10, 8: 5, 10: 5 };
```

数值表示权重，权重越高，出现概率越大。
